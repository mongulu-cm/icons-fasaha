🎨 Système de gestion SVG

Transformez vos fichiers SVG en composants React automatiquement

🔄 Workflow de conversion

1

Ajouter un SVG

Placez votre fichier SVG dans le répertoire assets/svg/ ou utilisez le gestionnaire interactif.

npm run svg:add
2

Traiter les fichiers

Le script nettoie le contenu SVG et génère automatiquement les composants React.

npm run svg:process
3

Utiliser les composants

Importez et utilisez vos icônes dans vos applications React.

import { Elephant, Baobab } from 'icons-fasaha';

🛠️ Scripts disponibles

📝

Gestionnaire interactif

Interface en ligne de commande pour ajouter, lister et supprimer des fichiers SVG facilement.

npm run svg:add
🔄

Traitement en lot

Traite tous les fichiers SVG du répertoire et génère les composants React correspondants.

npm run svg:process
📋

Fichier d'exemple

Crée un fichier SVG d'exemple pour commencer rapidement.

npm run svg:example

📁 Structure des répertoires

icons-fasaha/ ├── assets/ │ └── svg/ # Fichiers SVG sources │ ├── elephant.svg │ ├── baobab.svg │ ├── drum.svg │ └── ... ├── src/ │ ├── icons/ # Composants React générés │ │ ├── Elephant.tsx │ │ ├── Baobab.tsx │ │ ├── Drum.tsx │ │ └── index.ts │ └── utils/ │ ├── svgToComponent.ts # Utilitaires de conversion │ └── svgConfig.ts # Configuration └── scripts/ ├── process-svg-assets.js # Traitement en lot └── add-svg.js # Gestionnaire interactif

💡 Exemple d'utilisation

// 1. Ajouter un fichier SVG // Placez votre fichier dans assets/svg/mon-icone.svg // 2. Traiter les SVG npm run svg:process // 3. Utiliser dans votre code import { MonIcone } from 'icons-fasaha'; function App() { return ( <MonIcone size={32} color="#8B4513" /> ); }
